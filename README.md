# to do list

## Description

A simple to-do list website made with HTML, CSS and JavaScript only.
No backend.
Works on desktop and mobile (responsive).

# Component

1. Profile : name + division/position
2. Time : day, date, live clock
3. Text area : write the task
4. Priority : dropdown: low / medium / high
5. Submit button : adds the task to the list
6. Checkbox : mark task as done
7. To Do : list of tasks still on going + "Next up"
8. Done : list of finished tasks
9. Delete all button : removes every task
10. Delete button : removes one task
11. Deadline : date input (needed for "ex: complete on 30 May 2026")

## Features

- Allows users to add tasks through the website with a title, priority, and deadline.
- Shows today's day and date, plus a live clock.
- Checkbox: completed tasks are crossed out and moved to the DONE list.
- Allows users to delete one task or delete all tasks.
- Shows when each task was added.
- Remembers the user (name + division) so they don't have to enter it every time.
- Overdue tasks appear first because they're already late.
- Task sorting order:
  1.  Overdue tasks first.
  2.  Priority: High → Medium → Low.
  3.  Deadline: earliest date first when priority is the same.
